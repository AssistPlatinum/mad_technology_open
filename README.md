# Безумные Технологии — открытые файлы

Картинки-заголовки постов Telegram-канала [Безумные Технологии](https://t.me/Mad_Technology): утренний выпуск, «Итоги дня», карта трендов, посты недели и месяца, идеи.

Лежат в открытом доступе, чтобы Telegram мог показать их крупным превью над текстом поста. Код канала — в закрытом репозитории.
